# Switching and Routing Essentials
Cisco Network Security Project
Overview

This project was completed as part of my Bachelor of Computer Science (Cyber Security) coursework. The project focuses on designing, configuring and securing a network infrastructure using Cisco Packet Tracer.

Tools & Technologies
Cisco Packet Tracer
VLAN
DHCP
OSPF
NAT
HSRP
STP
Port Security
DHCP Snooping
Main Tasks
Designed a multi-site network topology.
Configured VLANs for network segmentation.
Implemented DHCP for automatic IP address allocation.
Configured OSPF for dynamic routing.
Implemented NAT for network communication.
Configured HSRP for network redundancy.
Configured STP to manage Layer 2 network paths.
Applied Port Security and DHCP Snooping to improve network security.
Tested network connectivity and verified configurations.
Project Structure
Packet-Tracer/     - Cisco Packet Tracer files
Documentation/     - Project documentation

Learning Outcomes
Through this project, I gained practical experience in network configuration, troubleshooting, routing, VLAN segmentation and Layer 2 security.
